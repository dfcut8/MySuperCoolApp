# Repository instructions

## Completing work

- Each time you finish a job that changes this repository, commit the completed changes on a feature branch, push the branch, and open a pull request on GitHub using the GitHub CLI (`gh`).
- Include a concise description of the changes and any relevant validation in the pull request, and share its link with the user.
- Do not merge the pull request until the user approves it.

## Approval and cleanup

- After a pull request is open, the user's message `lgtm` authorizes you to merge that pull request and delete its branch.
- Use the GitHub CLI to merge the approved pull request and delete the feature branch locally and on GitHub. Never delete the default branch.
